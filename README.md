# ln-lore-pipeline

**轻小说全本项目流水线技能包**——教 AI 代理把一部轻小说/web 小说全本，从原文清洗一直到生成 SillyTavern 可导入的「角色卡 + 世界书 + 年表」完整体系的 Agent Skill。

来自一个 37 角色 / 37 本世界书 / 12 章语料 / 1201 事件年表的真实项目全流程沉淀，每条规则都有实战事故背书。

## 它能做什么

```
原文全本 ─→ 语料清洗标注(L号坐标系) ─→ 角色语料/知识库 ─→ 事件年表(五层时间架构)
        ─→ 世界书(共通+每角色专属,泄底门控) ─→ 角色卡(V2+防串线) ─→ 十维审查
        ─→ 断言式修复 ─→ 酒馆 PNG 发布(自动挂载)
```

- 新项目：从零建卡/书/年表
- 存量项目：全面校验、异名治理、泄底审查、修复
- 发布：PNG 注入、世界书 JSON、审查合并文件

## 安装（草履虫版）

1. 下载本仓库 ZIP（Code → Download ZIP）并解压
2. 把里面的 `ln-lore-pipeline` 文件夹整个复制到你的 AI 工具 skills 目录：
   - ZCode：`C:\你的用户名\.zcode\skills\`
   - Claude Code：`C:\你的用户名\.claude\skills\`
3. 重启 AI 工具，开聊

更详细的图文说明（含常见问题）见 [`ln-lore-pipeline/安装说明.md`](ln-lore-pipeline/安装说明.md)。

## 使用

对话里提到 **轻小说 / 角色卡 / 世界书 / 年表 / 语料清洗 / SillyTavern / 校验审查 / PNG 注入** 等关键词会自动触发；也可以直接说"用 ln-lore-pipeline 帮我把 XXX.txt 做成角色卡"。

环境要求：Python 3.10+（仅运行 scripts/ 时需要），核心功能全离线。

## 包结构

```
ln-lore-pipeline/
├── SKILL.md            主说明书（流程路由 + 十二军规 + 高危问题模式）
├── references/         阶段指南×5（建设/审查/治理/发布/检查单）
├── scripts/            机械审计 · 审查合并 · PNG 注入
└── assets/             角色卡/世界书/审查任务书模板
```

## 亮点

- **证据纪律**：语料只读、引文逐字、L 号坐标系、"以书反推原文＝循环论证"禁令
- **审查工程学**：机械审计 + 子代理十维四对照 + 泄底启发式 + 判例传递
- **修复工程学**：断言式落盘、幂等、冻结字段、失败零写入
- **已知坑全登记**：内嵌书导入失败兜底、字段截断、BOM、L 号惯例偏移…
