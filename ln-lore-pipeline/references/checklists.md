## I. 替换脚本工程学速查（断言式修改的实战坑）

1. **码点先验**：精确替换失败时先 `repr()` 打印目标区实际码点——引号形制（「』""混用）、不可见字符是惯犯
2. **短锚点切片**：长串断言反复失败时改"前后短锚点 find + 区间切片替换"，锚点选 ≤10 字且唯一
3. **期望计数动态校准**：多步替换时后步期望数＝原始数－前序步骤消化量（每步执行前现数）
4. **白名单遮蔽计数**：判"旧形残留"先把合法保留串（异写标注/判例保护句）replace 成哨兵再计数
5. **长脚本落盘**：>60 行 Python 用 Write 工具写 .py 再执行；bash heredoc 超长会静默截断
6. **脚本必冒烟**：新脚本必须真实数据冒烟（正例＋应跳过例）通过才入包
