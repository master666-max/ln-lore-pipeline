# 审查体系（阶段7）：机械审计 ＋ 十维四对照 ＋ 修复工程学

## 7.1 机械审计（主代理脚本只读跑，scripts/audit_cards.py）

1. **结构审计**：spec=chara_card_v2、七关键字段非空、JSON 合法、无 BOM、体量分布
2. **宏审计**：{{char}}/{{user}}/标准宏之外的残留宏
3. **泄底启发式**：抽取对应世界书 disable 条目正文（去注释后按句切分）的 ≥14 字句，在卡活跃字段（description/personality/scenario/first_mes/mes_example/system_prompt/PI）做子串搜索
4. **L 号引文直核**：卡内「引文」（Lxxxx）→ 语料对应章 L±4 行检索引文头 8 字；**惯例偏移规则**：标注 L 常落在引文前 1~3 行叙述行，±3 且说话人、文字逐字相符＝相符，仅文字/归属实错＝漂移
5. **变体扫描**：异名组 × 卡/书两层全量计数（对照组见异名统合表）
6. **章号归属核对**：L 号所标章 vs 语料实际所在章（实战：7-2 章 L 号被标成 7-3 章）

## 7.2 子代理深审（十维四对照）

**必对照四方**：角色专属世界书（事实权威）＋共通世界书＋卡＋异名统合表。
**按需旁证**：角色库、清洗标注版、年表。
**分批**：4~5 卡/批；任务书 txt 固化（assets/review_prompt_template.md）；判级规则随判例逐批传递；**并发按自适应探测策略**（只读审查类可激进并行，写盘类保守），主代理逐批独立断言验收。

**十维**：
① 事实一致性（含主客方向、亲疏变化）② 剧透管控（结合卡自述默认时段判性；PI 隐瞒指令不计泄底，但活跃字段已泄＝泄底为准）③ 台词指纹（归属链核验、编造咏唱）④ L 号引文逐条直核（含惯例偏移）⑤ 表达层（错字/语病/占位符/截断尾）⑥ 机械线索复核 ⑦ 统计残留检查 ⑧ **数值面板**（HP/MP 状态栏 vs 语料状态栏原文）⑨ **称呼方式**（本角对他者称谓体系）⑩ **关系亲疏变化**（随卷次演化的前后态）

**发现记录五要素（强制）**：【卡内原文】【语料出处（文件名+章节）】【差异说明】【建议改为】【置信度 高/中/低】——证据不足一律降置信度，禁止编造补齐。

**输出**：完整审查结果，逐卡逐维全列不压缩；P0/P1 必附双方证据原文；逐角色出报告 `校验-{角色名}.md`＋汇总总表（批报告降为归档容器）。

## 7.3 双向验证与双版本（吸收自外部校验 SOP）

- **世界书双向验证**：①专有名词全量普查（人名/地名/组织/楼层守护者/技能/道具/术语/事件×频次）→ 高频无条目者写新增草稿（触发词 3~8 个含别名变体、内容标注出处、附优先级）；②反向：世界书条目逐条回扫语料，无据者标"疑似二创/误记"供裁决
- **防呆**：反向判定前必须过异名变体归一＋L 号惯例偏移，否则误判"无据"（实战："过度吸引魔力的体质"换了 3 个位置才定位到第八章 L12248）
- **web/文库双版本**：同一设定两版不同→分别标出处＋提醒选基准（默认 web 版基准）

## 7.4 典型问题模式（实战频率排序）

1. 常驻字段复刻 disable 条目（scenario 整段终局清单/personality 例句/system_prompt 称号）→ P0 最高频
2. personality 例句引 disable 逐字台词 → 第二高频且最易漏审
3. 事实错误：主语错置/归属反置/张冠李戴（怀疑对象 A 写成 B）/主客颠倒/方向反置 → 语料直证才能发现
4. scenario 400/420 字管道截断（残句若触禁用内容随泄底一并处理）
5. 引号内措辞与原句不一致；压缩转引带引号
6. 统计残留混入活跃字段
7. 自创口癖句带引号冒充原文
8. 书侧/共通侧缺陷回流（章号错/台词误归/引文扩写/极性反转）——审查要覆盖书侧，注明"错在书侧"

## 7.5 修复执行（阶段8）

- 报告批准后分两档：**肯定错误**（免审：定案异名/客观错字/泄底撤出/截断尾/语料直证的事实错误）与**人工决策**（待裁项/措辞二选一）
- 两阶段：Phase1 机械项主代理断言脚本直跑；Phase2 按批子代理（读报告取证据→断言式精确修改→自检→≤15 行摘要）
- **修复工程学**：断言式（命中数断言）＋幂等（已改＝跳过）＋冻结字段逐字段比对＋内存构建全过才落盘＋失败零写入＋落盘重读复检
- 修复后：双层复检（泄底启发式清零＋变体清零）→ 重造审查合并 → 报告补执行记录
- **范围外残留制度**：子代理发现 ● 项外问题→"按纪律未动，提请定夺"，主代理汇总统一补刀
