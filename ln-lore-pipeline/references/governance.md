# 治理总纲：军规 / 判例 / 合并规格 / 子代理协议 / 特别设定通道

## 十二军规（宪法级，一切阶段适用）

1. **语料只读**：证据权威永不修改；误写登记《已知误写清单》（用户拍板原则：原译本混乱只需书卡统一，语料不动）。用户明确解冻时逐处登记《勘校记录》再动
2. **三源对照**：卡↔书↔语料至少两源；**严禁以世界书记载反推原文**（防循环论证）
3. **断言式＋幂等**：替换前断言旧串命中数；内存构建、断言全过才统一落盘；任一失败零写入；落盘重读复检
4. **引文逐字**：「」台词不润色/不拼接/不改归属；例外仅限判例定案；引号措辞与原句不符→改逐字或去引号
5. **判例积累**：每项裁定入《判例集》《异名统合表》，照表执行禁止重裁；冲突提交用户拍板
6. **冻结字段**：批量修复明列冻结清单（name/文件名/creator_notes/tags/first_mes 等），落盘后逐字段比对
7. **P0/P1/P2**：P0=事实错误/泄底/串线（必修）；P1=建议修；P2=备案/表达层；分级标准随判例传递
8. **批次文档**：`_bN*_调度_日期\`：prompts\ txt 固化＋results\ 归档＋结果汇总 md＋改前基线快照；交接文档会过时，批次汇总是实时真相
9. **子代理运行方式不预设、过程中动态决定**——综合任务性质/前序产出/当前环境随时切换：后段依赖前段产出的工作＝串行＋链式传递；对象互不依赖＝可并行探测（判定与切换规范见「子代理协议·运行方式动态判定」节）
10. **报告先审后改**：批准前零修改；"肯定错误"（免审）与"人工决策"分档
11. **泄底门控**：后期揭示→disable 手动条目；常驻字段禁复刻；PHI 不是泄底遮羞布
12. **自主提案不入正式文件**：特别设定走 §13 提案→人工审核门
13. **Git 版本治理**：批次双 commit（基线/成果）、发布打 tag、回滚用 checkout——详见 references/git-governance.md

## 判例与异名治理

### 异名统合表结构（项目核心资产）
定案用字总表｜书层已修清单（注明"书已修、卡未修"）｜书卡对照实测表｜📌设计性异写保留清单（异写标注/keys 并写/引文逐字三类）｜语料误写清单｜防串线足名｜**时间层通则**（译名随卷次漂移时：后期卷＋本人亲口台词＝最高证据）｜待裁项｜按对象动作清单。

### 机制
16 组变体 × 书卡两层全量扫描 → 逐处人工判性（叙述/引文/标注）→ 定案 → 断言式执行 → 回写执行记录。新会话/精修照表执行，禁止重新裁定。

### 判例格式示例
- 希丝＝西斯（转录误写，含引文全纠）｜三形勒家名→统一形（源文查库 504 处逐处归档＋用户拍板；源文家族名＝使徒名同形→R4 全名/职名防串线）｜守护炎→守护之炎（L19902 主用字）｜跨书姓氏以主用字书为准｜身体登记名保留不清理
- **判例保留区**：keys 异写并写＝触发面设计勿清理；content 内"旧译异写"标注原样保留

## 审查合并文件规格（供强模型离线审查）

1. 文件名权威序列排序（一旦确立永不变更——位置稳定性防"尾部截断"错觉）
2. **按字数 DP 均衡切份**（每份 ≤~1800 行，任何一份单次可读完；目标 min-max 最优）
3. 分 2 文件夹（累计字数差最小）
4. 每文件前插独立成行 `===== 文件名 =====` 标题；**前文件无尾换行则强制补**（根治粘连）
5. 字节原样拼接 → UTF-8 无 BOM → SHA256 回验（内存重建流==落盘字节）
6. **拆解 QA**：从合并文件反向拆出每个 JSON 独立解析
7. 版本命名 `Bn后_*`；新版重造后旧版删除（缺陷版必须移除防误用）；清单.json（逐份书目/行数/SHA256）随附

## 子代理协议

### 运行方式动态判定（不预设，过程中可变）

| 方式 | 判定（综合任务性质/前序产出/当前环境） | 执行 |
|---|---|---|
| **串行＋链式传递** | 后段工作需要前面 n 个代理的产出才能继续（不限小说：剧情连贯/累积归纳/世界观递进/多轮迭代） | 每代理读共享 GUIDE＋前序全部产物＋滚动摘要 |
| **自适应并行** | 各对象仅凭共享上下文即可独立完成（单卡/单书/单文件/机械批量） | 探测：2 起步错开启动/成功递增/限流等待重试或降档 |

**动态切换条款（关键）**：
- 判定**不是开头一次性定死**——同一任务可在不同阶段采用不同方式（如前期探索/依赖前序＝串行，进入批量对象处理＝并行），发现新依赖或依赖解除时**随时切换**
- 主代理综合判定依据：①任务对象间有无实质依赖 ②前序产出是否已被后续消费 ③当前限流/连通状态 ④进度与剩余量
- 切换时保证衔接：串行→并行前确认各对象已无前序依赖；并行→串行前确认已产出产物已归档为可传递上下文

**剧情依赖型的链式传递规范（串行时）**：
1. 先一次性生成**共享权威 GUIDE**（路径/字段定义/时间架构/别名表——迷深实证：`_子代理上下文_GUIDE.md` 模式，全员同一份，分发给每个子代理）
2. 每个子代理的任务书必须包含：①GUIDE ②**前序全部代理的产物文件路径清单（必须逐个 Read，不只是上一个）** ③本代理负责的增量范围
3. 每个代理除交付文件外，必须输出**滚动摘要**（本段新增剧情要点/新角色/新设定，追加到共享摘要文件）——供后续代理与主代理追踪
4. 主代理派发下一代理前，把"前序产物清单＋最新滚动摘要"写进其任务书
5. 串行的代价用"切包"控制：每包 90~170KB（迷深实测），代理只读 GUIDE＋自己的包＋前序摘要，不全读语料

**对象独立型的并行前置**（缺一不可）：对象文件互不重叠、修改断言式+幂等、失败零写入、提示词 txt 固化、验收脚本独立；探测：2 起步错开启动/成功递增/限流等待 60~120s 重试或降档记录稳定值


- **提示词 txt 固化**：主代理组装"通用纪律＋对象专属 ●项"写 prompts\，子代理 Read 后执行——防截断/可追溯/可重跑
- **前后台**：后台防对话打断（推荐）；前台结果直传但插话即取消
- **故障处理**：API 中断→确认零写入→重跑（幂等保证无污染）；双实例收敛（后发现者转核验模式）；并发限制→全批等待 60~120s 重试一次，再失败降档并记录稳定并发数
- **验收**：主代理独立脚本逐项断言（新文案在位/旧文案消失/计数一致/冻结字段未变/结构不变），不过打回
- **进度持久化**：reports/progress.md（已完成阶段/发现数量/下阶段计划），中断后先读再续，禁止重头开始
- **记忆回写**：批次后更新跨会话记忆（交接文档会过时，记忆才是实时真相）
- **metadata.json 诊断法**：子代理疑似挂死时查其 metadata.json——status/距上次更新秒数/totalToolUseCount 与 totalTokens 全空＝首次模型请求即挂死（等 1~3 分钟无动静即放弃重拉）；任务记录被销毁时 SendMessage 不可用，只能重拉新实例（幂等保证无污染）
- **通知丢失恢复**：后台代理完成通知可能丢失——从其 output.txt（JSONL）提取最后一条 assistant 消息即可追认并归档
- **文件系统抖动**：同一路径 exists→open 闪变失败（疑似杀软扫描），脚本一律带 rob_open 重试（4 次×1.2s）
- **接管协议**（新会话接手存量项目）：①按序读交接/记忆文件 ②抽验 3~6 个成品跑全绿断言 ③汇报"已接管、基线确认、最新批次、待命"——禁止按旧文档基线重跑历史

## 元方法（流程级经验）

- **可行性论证先行**：涉新格式/新机制的任务（如"一张 PNG 导全部"），先出可行性论证（含格式硬上限认知与备选方案表），用户拍板方案后再动工——不做可行性就直接实现，失败成本最高
- **外部审查交叉对比**：用另一模型独立审查同一批对象后，按"发现质量以本地为基准 + 执行粒度吸收对方现成句式"合并；对方 PASS 判定须逐张复核（实战中 3 张 PASS 全判错）
- **接手存量+新标准并存**：接手时只做增量（基线断言通过即承认历史），历史批次永不重跑

## §13 特别设定定制通道

**触发特征**（任一）：共体/容器/转生同体类｜角色即世界规则（魔法本体/系统化身）｜系统流数值面板为主体｜特殊文本形态为主体（咏唱/辞世诗/书信/剧中剧）｜非线性叙事主体｜跨卡联动结构。

**双输入通道**：
- **通道 A｜AI 自主提案**：产出《定制提案包》（设计动机＋L 号证据/结构设计＋兼容性/示例条目按格式军规含 disable 门控/影响评估/回滚方案）→ 写入 `提案\` 目录，**未批准不得写入任何正式文件**
- **通道 B｜人工直供**：用户直接输入 → AI 不发挥，只格式化＋一致性校验（与语料冲突提示不擅裁）＋落盘标【用户直供】

**来源效力**：语料 ＞ 判例 ＞【用户直供·用户主权】（冲突时提示拍板，拍板后登记判例）＞ AI 提案（未批准＝零效力）。

**自主边界**：可自主＝段位/字段/触发体系设计、示例条目、回归脚本；不可自主＝动判例与统合表、违反格式军规、弱化泄底门控、提案直写正式文件。

**审核门检查单**：□标准结构真装不下 □语料证据成立 □无判例冲突 □泄底门控未弱化 □回归影响可接受 □回滚可行。批准后转正式批次（走修复工程学）。
