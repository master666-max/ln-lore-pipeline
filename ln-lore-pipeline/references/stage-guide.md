# 阶段 1~6 建设指南（语料→分析→知识库→年表→世界书→角色卡）

## 阶段1 语料层建设

### 原文分层
- web 版为主源（引文基准），文库版作对照（翻译用字可能不同，建《字词转换对照表》）
- 原始获取物不动，加工品入分析目录

### 清洗标注版（核心发明）
每章一份 `第X章_标题_清洗标注版.md`：
- **L 号＝章内行号**：全项目引用定位唯一坐标系；跨章引用必须带章号
- 每块前置头：`## block_id: md-XXXX  episode: 第N话 标题  edition: web_original  timeline: 千年前/千年后`
- 对白行 `[对白]` 前缀；叙述/对白分离；**说话人归属**就近标注（含"据 X 转述"转述链）
- 译者注/校对署名保留但隔离——不是角色台词（实战踩坑：译者 ID 被当角色台词）
- 原作特殊用法（着重号/半角标点/六点省略号）不得"校正"
- **edition 标记**：web_original（原生 web）/ web_reconstructed（文库转写重构）——转写章用字以《字词转换对照表》为准

### 配套索引
`_索引_章节话号映射.json`（话号↔章节↔block 区间）

### 验收
随机 ≥20 行与原文比对；章节覆盖全；block 编号连续；译注分离。

## 阶段2 全文分析

- **场景块语料**：逐章 json，对白/叙述分块、场景切分、人物出场
- **角色语料库**：每角色五类证据（候选台词/紧凑包/派发/叙述证据/证据包）＋全量索引
- **归属定稿**：台词→角色，含转述链标注
- **画像量化**：句长/虚词密度/MATTR/Delta/LL/PMI/共现/TextRank——**只用于指纹校验，严禁注入卡活跃字段**

## 阶段3 AI 知识库

每角色双库：
- **事实档案**：身份/称号/关系表（一行一证带 L 号）/履历/外貌（原文未载则写"未载，不得臆造"）
- **台词库**：Q 段位编号＋逐字台词＋L 号＋语境＋转述链

配套：世界观知识库、关系网（按簇：镜像/救赎/师承/姐妹/使徒/契约/守护者/阵营）。

**验收**：每角色 ≥3 条事实回核语料。三方同源错读（卡/书/库同错）必须回溯语料定案，禁止以错改错。

## 阶段4 年表工程

### 时间架构先行（最不可跳过）
- **双轨标注**：每事件同时记 `story_anchor`（叙事讲述点）与 `event_time`（实际发生点）——混淆＝年表写崩
- **五层架构**（按作品调整）：T0 现代（年→月）/ T1 远古战争（月→周）/ T2 建设期（月→周）/ T3 主线（日→时）/ T4 间隔千年（百年＋节点）

### 事件字段 schema（缺一不可）
event_id（分层编号）/ event_time / story_anchor / title（≤20字）/ description（100~300字含关键原句）/ characters（含化名标注）/ location / 伏笔反转标记

### 提取-合并流水线
分章切包（90~170KB）→ 子代理**单发分页**提取（每代理 1 包）→ 合并脚本（去重＋分层重编号＋排序）→ 修复脚本（控制字符/引号）→ 缺口与覆盖分析

### 质量审计与裁决
未决事项决策清单（现状/证据/建议默认值/备选 → 用户拍板）→ 检验报告（L 号直证）→ QA 多轮＋自审查多遍记录。锚点重叠≠同一事件（多事件共享 block 正常）。

### 交付与维护协议
- 七件套 JSON+YAML 双份（timeline_index/full_event_list/foreshadow_chains/reversal_nodes/incantation_links/conflict_report/confidence_stats）
- 交付四件套：01 全量 md｜02 AI 知识库时间线｜03 酒馆时间线 json｜04 按年限跳转 docx｜05 含伏笔 docx
- **维护铁律**：原文不改｜改前备份 _backup_*｜双格式同步｜镜像三同步｜改后重建链（聚合器→生成脚本→README 计数）｜易混名红线复查

### 验收
时间线单向性；每事件可回溯 L 号；可反向用年表核角色卡话号倒挂与时序。

## 阶段5 世界书构建

### 共通世界书（1 本）
逐层体系（如迷宫 0~120 层守护者/辞世诗）、魔法体系、阵营、地理、宗教、概念、千年时间线、群像。
格式：ST 世界书导出格式。**共通书同样要过审查**（实战查出 3 处缺陷）。

### 角色专属世界书 uid0~9 十段结构

| uid | 段 | 内容 |
|---|---|---|
| 0 | ①核心元数据(卡外) | 全名/异写/自称/身份/防串线句；constant=false |
| 1 | ②关系·羁绊 | 关系人名行（一行一证带 L 号） |
| 2 | ③前期锚点 | 低剧透事件 |
| 3 | ③'终局锚点 | disable 手动 |
| 4 | ⑤力量·战斗 | 能力词触发；不编造咏唱 |
| 5 | ⑥语言指纹·防串线 | 句式DNA/称呼体系/引用守则 |
| 6 | ⑦台词库 | 「」逐字＋话号，注明"说话者＝本人" |
| 7~9 | ⑦'⑨终局/红线条目 | disable 手动 |

### 格式军规九条（全绿断言脚本逐条检查）
① position=4/depth=4/prevent_recursion=true（root+extensions 双层）；② constant:true＝0；③ disable 条目 root+extensions 双层＋content 首行 `<!--【手动条目】…-->`；④ 每条末行 `<!-- 触发逻辑：…；剧透等级：X -->`；⑤ uid 顺序不变；⑥ key==keys 镜像；⑦ keys 异写并写（触发面设计勿清理）；⑧ UTF-8 无 BOM；⑨ 禁用旧形词＝0（判例保护除外）。

### 泄底管控
后期揭示 → disable 手动条目；活跃条目只留指针句：「后期线详见专属世界书手动条目（剧情推进后启用）。」

### 引用守则
「」逐字；无咏唱不编造；他人台词不安入；**L 号加注前必须直核**（实战：B12 所加 L12097 复核查实应在 L12573）。

## 阶段6 角色卡构建（V2）

### 结构
`spec: chara_card_v2`；data 七关键字段＋PI（post_history_instructions）＋extensions.depth_prompt＋alternate_greetings＋creator_notes＋tags。

### 写法
- **description**：身份＋外貌（未载则声明）＋性格层次（表层/深层/破绽前兆）＋关系一句定性＋能力概览（不泄底粒度）＋负空间
- **personality**：语言指纹（自称/句式DNA/口癖/语域切换/关键词Top）＋例句（**必须活跃层台词**，严禁 disable 引文）；禁统计残留
- **scenario**：话号锚点式，只到默认时段；后期→指针句
- **first_mes/AG/mes_example**：创作台词守指纹；引用源文场景可回溯
- **PI 红线**：隐瞒清单＋"掌握≠揭示"——注意 **PI 不是泄底遮羞布**：活跃字段已泄的内容不受 PI 保护（实战判例）

### 防串线
三人共名类必须全名/职名区分；他人台词安入、视角台词未标注、标志行为错安＝P0/P1；主客方向核对（"A 是 B 的救命恩人"别写反）。
