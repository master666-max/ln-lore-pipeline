# 安装说明（草履虫版——照着点就行）

## 这是什么？
一个教 AI 打理"轻小说 → 角色卡 + 世界书 + 年表"的技能包。
装好之后，你对 AI 说"我要给这本小说做角色卡"，它就会按一套经过实战验证的流程干活（清洗原文 → 分析角色 → 写年表 → 建世界书 → 建角色卡 → 审查 → 生成酒馆能导入的 PNG）。

## 包里有啥？（不用看，知道就行）
```
ln-lore-pipeline/
├── SKILL.md            ← AI 读的主说明书（必须）
├── 安装说明.md          ← 你正在看的这个
├── references/          ← 5 份分阶段详细指南（AI 按需自己读）
├── scripts/             ← 3 个 Python 脚本（审计/合并/PNG注入）
└── assets/              ← 角色卡、世界书、审查任务书的模板
```

## 怎么装？（共 3 步）

### 第 1 步：解压
把压缩包解压，得到一个叫 `ln-lore-pipeline` 的文件夹。
（确认里面直接就是 SKILL.md——不是"ln-lore-pipeline/ln-lore-pipeline/SKILL.md"那种套娃）

### 第 2 步：把整个文件夹复制到技能目录
按你用的 AI 工具，把 `ln-lore-pipeline` 文件夹整个复制到：

| 你用的工具 | 复制到这个位置 |
|---|---|
| ZCode | `C:\你的用户名\.zcode\skills\` |
| Claude Code | `C:\你的用户名\.claude\skills\` |
| 其他支持 Agent Skills 的工具 | 该工具的 skills 目录（找找设置里"skills"或"技能"字样） |

> 不知道"你的用户名"是啥？按 Win+R，输入 `.`，回车，打开的就是你的用户文件夹。

### 第 3 步：重启你的 AI 工具
关掉重开（或新开会话），完事。

## 怎么确认装好了？
新会话里问 AI 一句：**"你有没有 ln-lore-pipeline 这个技能？"**
它答有（或列出技能清单里能看到）＝装好了。

## 怎么用？
对话里只要提到这些词，AI 大概率自动用它：
**轻小说、角色卡、世界书、年表、语料清洗、SillyTavern、校验审查、PNG 注入**
也可以直接命令式使用："用 ln-lore-pipeline，帮我把 XXX.txt 这本小说做成角色卡"。

## 需要什么环境？
- Python 3.10 或更高（只有跑 scripts/ 里 3 个脚本时才需要；Windows 用户命令用 `py` 不是 `python`）
- 不联网也能用（核心功能全离线）

## 常见问题
| 问题 | 解法 |
|---|---|
| AI 说没这个技能 | ①确认文件夹名是 `ln-lore-pipeline`（没改名）②确认 SKILL.md 直接在文件夹第一层 ③重启工具 |
| 想卸载 | 删掉 skills 目录里的 `ln-lore-pipeline` 文件夹，完 |
| 脚本报错 | 确认用 `py 脚本名` 运行（Windows）；路径含中文没问题 |
| 想改技能内容 | 用记事本打开 SKILL.md 直接改，保存即生效 |

## 一句话版本
**解压 → 把 `ln-lore-pipeline` 文件夹丢进 skills 目录 → 重启 → 开聊。**
